# عناوين التوصيل في التطبيق

يظهر عنوان التوصيل أعلى الرئيسية بدلاً من الشعار. الضغط عليه يفتح قائمة العناوين؛ إضافة عنوان تفتح اختيار الموقع ثم تفاصيل الاسم والمبنى والطابق والشقة والملاحظات.

## تفعيل حفظ عناوين الحساب

يشغّل مالك المشروع ملف [20260910060000_delivery_addresses.sql](../supabase/migrations/20260910060000_delivery_addresses.sql) في **Supabase → SQL Editor → New query → Run**. الملف قابل لإعادة التشغيل، ولم يُطبّق تلقائياً على قاعدة الموقع.

بعد التطبيق، أعد تحميل الصفحة أو افتح قائمة العناوين مجدداً. العناوين والاختيار الافتراضي مرتبطان بحساب المستخدم ويظهران على أجهزته بعد تحميل القائمة أو تحديثها. لا تحتاج الخدمة مفاتيح سرية أو دلو صور.

إذا لم يُطبّق الملف أو تعذر الاتصال، يظهر خطأ تحميل/حفظ للحساب؛ لا يستبدل التطبيق حفظ الخادم بحفظ محلي يوهم المستخدم بالمزامنة. يستطيع الزائر إضافة عناوين محفوظة على جهازه فقط، وتوضح الواجهة ذلك. بيانات الزائر مستقلة ولا تنتقل تلقائياً إلى حساب عند تسجيل الدخول.

## البيانات والصلاحيات

- جدول `delivery_addresses` خاص بصاحب الحساب عبر `auth.uid()` وRLS، دون صلاحية قراءة للزائر أو استثناء للمدير.
- الكتابة المباشرة ممنوعة. تستعمل الخدمة RPC للحفظ والاختيار والحذف مع قفل خاص بالحساب، للحفاظ على عنوان افتراضي واحد وحد أقصى **20 عنواناً**.
- كل طلب كتابة يحمل معرف الحساب المتوقع؛ يرفضه الخادم إذا تغيرت الجلسة قبل وصول الطلب. التطبيق يحجب بيانات الحساب السابق فور التبديل ويتجاهل الردود المتأخرة.
- حفظ عنوان يجعله المختار. حذف العنوان المختار يختار أول عنوان متبقٍ. حذف الحساب يحذف عناوينه تلقائياً.
- التحقق يشمل إحداثيات محدودة وصحيحة، اسم العنوان حتى 60 حرفاً، وصف العنوان 500، المبنى 80، الطابق والشقة 40 لكل منهما، والملاحظات 500.

هذه الميزة تدير دفتر العناوين والاختيار في الرئيسية. لا تغيّر الطلبات السابقة ولا تضيف تلقائياً العنوان إلى سجلات الطلبات أو الفواتير؛ ربط نسخة عنوان ثابتة بطلب جديد يحتاج تغييراً مستقلاً في مسار إنشاء الطلب.

## الخريطة والبحث

الخريطة تفاعلية من OpenStreetMap مع إسناد ظاهر، والبحث وقراءة اسم الموقع عبر [Photon](https://github.com/komoot/photon). يبدأ العرض من الرياض دون اعتبارها موقع المستخدم. يُحدّد موقع التوصيل بتحريك الخريطة أو البحث عن عنوان أو زر «موقعي الحالي»، الذي يطلب إذن الموقع عند الضغط عليه فقط. عند رفض الإذن يبقى اختيار الموقع بالخريطة أو البحث متاحًا، ولا يوجد خيار لإدخال الإحداثيات يدويًا.

البحث يتم عند الإرسال، وتُجمع طلبات تحريك الخريطة مع فاصل زمني وذاكرة مؤقتة. يمكن تغيير خادم البحث وقت البناء بواسطة `--dart-define=SF_GEOCODING_BASE_URL=https://your-photon-server.example`. خدمة Photon العامة للاستخدام المعقول ولا تضمن التوافر، وتخضع صور الخريطة إلى [سياسة OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/). عند تعذّر قراءة اسم الشارع، يحتفظ التطبيق بنقطة الدبوس ويتيح إدخال العنوان في نموذج التفاصيل.

أُضيف إذن الموقع أثناء الاستخدام إلى إعدادات Android. المشروع الحالي يضم Android وWeb؛ لا يحتوي مجلد iOS لإضافة وصف الإذن إليه.

## التحقق

اختبارات الخدمة تغطي حفظ الزائر، استعادة الاختيار، تسلسل الكتابات، فشل التخزين، حفظ الخادم واستعادته على جهاز آخر، منع الحفظ المحلي للحساب، وتبديل الحساب أثناء الطلبات.

لاختبار SQL في PostgreSQL معزول باستخدام حزمة PGlite مثبتة خارج المستودع:

```powershell
node scripts/test_delivery_addresses.mjs <temporary-pglite-package-directory>
```

يغطي الاختبار إعادة تطبيق الترحيل، صلاحيات القراءة والكتابة، العزل بين حسابين، رفض سياق جلسة قديم، ذرية الاختيار، حد العناوين، التحقق من المدخلات، وحذف بيانات الحساب. لا يتصل بقاعدة الموقع.
